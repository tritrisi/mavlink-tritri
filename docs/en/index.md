# TRITRI MAVLink dialect

TRITRI is a downstream [MAVLink 2](https://mavlink.io) dialect for Speed0
counter-UAS command and control. It layers private COP messages on top of the
shared [MAVLink-M](https://github.com/Dronecode/mavlink-military) vocabulary
(`53000-53099`).

MAVLink-M covers coordination and situational awareness between uncrewed
platforms and command systems. TRITRI adds program-specific track and target
messages in the private `53900-53999` block. See
[Scope and Boundaries](about/scope.md) for what the shared dialect deliberately
does and does not carry.
